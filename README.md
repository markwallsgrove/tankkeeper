# Tankkeeper

Talk to Claude about your fish tank.

Tankkeeper is a Home Assistant integration for a planted aquarium. It keeps the tank's plan, log, contents, products and decisions, runs the reminders and checks the tank's status. It is MCP first: you set it up, change it and ask about it in a conversation with Claude, from Claude Code over MCP or from Assist in Home Assistant. Conversations are kept, so you and Claude can look back on them. The panel is the fallback.
